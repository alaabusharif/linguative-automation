# 02 — Capability Matrix

One row per **capability**, not per agent/routine — several routines bundle multiple capabilities (e.g. Sales Agent alone is 8). Recommendation values: **KEEP** (stays with Claude Code as-is), **MERGE** (folds into a named consolidated owner), **ARCHIVE** (kept, not primary), **RETIRE AFTER TEST** (superseded once parity is proven), **DO NOT RETIRE** (unique, no current replacement).
